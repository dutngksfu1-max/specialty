# teacher-style-v1 검증 계획 — B-1 → C → B-2

> 작성일: 2026-08-20  
> 현재 상태: **B-1 구현 완료 · C 인터뷰 준비 완료 · 실제 교사 데이터 대기**  
> 관련 결정: DEC-023 · DEC-024 · DEC-038 · DEC-046

이 문서는 검사 문항과 결과 문구를 그럴듯하게 다듬는 데서 끝내지 않고,
실제 교사가 문항을 어떻게 이해하는지 확인한 뒤 B-2를 확정하기 위한 작업 기준입니다.
인터뷰와 파일럿 결과가 나오기 전에는 문항 교체·점수 경계·최종 결과 문구를 확정하지 않습니다.

## 1. 단계와 진입 조건

| 단계 | 상태 | 하는 일 | 완료 조건 |
|---|---|---|---|
| B-1 안전 보정 | 완료 | 맥락 비약 제거, 균형·강도 반영, 어려운 소제목 수정 | 자동 검사·타입 검사·빌드 통과 |
| C-1 인지 인터뷰 | 준비 완료 | 교사가 문항을 어떤 뜻과 장면으로 읽는지 확인 | 고위험 문항마다 유지/수정/제거 근거 확보 |
| C-2 수정 문항 재확인 | 대기 | 수정 문항만 다시 읽혀 의도대로 이해되는지 확인 | 같은 오해가 반복되지 않음 |
| C-3 파일럿 | 대기 | 익명 응답으로 문항 분포·축 구조 확인 | 분석 계획에 따른 결과표와 해석 기록 |
| B-2 최종 보정 | 차단 | 문항·경계·결과 문구 확정 | C 결과 + 사용자 승인 + 새 DEC |

### 검증 원칙의 근거

- [교육·심리검사 표준](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)에 따라 먼저 의도한 점수 해석, 대상 집단, 측정 범위를 분명히 하고 그 해석을 뒷받침하는 근거를 모읍니다.
- 같은 표준이 구분하는 응답 과정 근거와 내부 구조 근거를 각각 확인합니다. 인터뷰가 통과했다고 축 구조가 입증되는 것도 아니고, 통계가 좋아 보인다고 문항이 의도대로 읽힌 것도 아닙니다.
- [미국 CDC의 인지 인터뷰 안내](https://www.cdc.gov/nchs/ccqder/question-evaluation/cognitive-interviewing.html)에 따라 이해·기억·판단·응답 선택 과정을 나누어 묻고, 참여자 사이와 하위 집단 사이의 해석 차이를 비교합니다.

## 4. C-1 교사 인지 인터뷰

### 참여 구성

- 무작위 대표 표본이 아니라 문제를 찾기 위한 목적 표집으로 진행하되, 경력·담당 학년·학교 규모가 한쪽에 몰리지 않게 구성합니다.
- 전체 목표는 20~30명, 한 차수는 6~10명을 작업 기준으로 둡니다. 이는 타당성을 보장하는 숫자가 아니라, CDC가 제시하는 소규모 인지 인터뷰 범위 안에서 수정과 재확인을 반복하기 위한 운영 목표입니다.
- 고위험 문항은 서로 다른 배경의 교사에게 반복 노출하고, 한 사람이 40문항을 모두 깊게 검토하느라 피로해지지 않도록 고위험 문항 묶음을 차수별로 나눕니다.
- 이름·학교명·연락처는 인터뷰 기록과 파일럿 데이터에 적지 않습니다.
- 참여자 수를 채웠다는 이유만으로 끝내지 않고, 마지막 차수에서 새로운 중대 오해가 나오는지 확인합니다.

### 진행 순서

1. 축 이름·의도·결과를 보여 주지 않은 상태에서 실제 앱으로 먼저 답하게 합니다.
2. 참여자가 떠오르는 생각을 말하게 하고, 인터뷰어는 먼저 방향을 제시하지 않습니다.
3. `이 문장은 무슨 뜻으로 읽혔나요?`처럼 이해 과정을 묻습니다.
4. `어떤 때를 떠올렸나요?`처럼 기억해 낸 기간과 장면을 묻습니다.
5. `답을 정할 때 무엇을 비교했나요?`처럼 판단 과정을 묻습니다.
6. `그 값을 고른 이유는 무엇인가요?`처럼 5점 응답에 옮긴 과정을 묻습니다.
7. 열린 질문이 끝난 뒤에만 상황 의존, 두 개념 혼합, 좋아 보이는 답, 학생·동료 맥락 혼동을 확인합니다.
8. 모든 문항 탐색이 끝난 뒤 결과 문장을 보여 주고, 응답보다 넓게 단정한 부분을 표시하게 합니다.

인터뷰어는 `그 뜻이 맞다`, `원래는 이런 뜻이다`라고 설명하거나 답을 칭찬하지 않습니다.
참여자가 뜻을 물으면 `정답을 알려 드리기보다 선생님께 어떻게 읽혔는지 먼저 알고 싶습니다`라고 답합니다.
설명이 필요했다면 문항이 스스로 뜻을 전달하지 못한 것으로 기록합니다.

### 문항마다 남길 기록

| 항목 | 기록 방법 |
|---|---|
| 익명 참여 코드 | 이름 대신 임의 코드 |
| 문항 ID | 코드 원문 그대로 |
| 참여자가 바꿔 말한 뜻 | 가능한 한 실제 표현 유지 |
| 떠올린 기간·기억 | 최근 한 장면 / 평소 전체 / 특정 학기 / 기억 어려움 |
| 떠올린 장면 | 학생 / 동료 / 학부모 / 업무 / 회복 / 기타 |
| 판단에 쓴 근거 | 실제 행동 / 바람직한 모습 / 역할 요구 / 감정 / 기타 |
| 응답값을 고른 이유 | 인접 값과 무엇이 달랐는지, 확신 정도 |
| 답하기 어려운 이유 | 상황 의존 / 두 가지를 함께 물음 / 경험 없음 / 표현 불명확 / 척도 구분 어려움 |
| 좋아 보인 선택 | 없음 / 앞쪽 / 뒤쪽 + 이유 |
| 판정 | 유지 / 수정 / 제거 후보 |

### 문항 판정 규칙

- `유지`: 의도한 한 개념으로 읽히고, 실제 장면을 떠올릴 수 있으며, 특정 답이 더 좋은 교사처럼 보이지 않습니다.
- `수정`: 핵심 개념은 맞지만 기간·대상·장면이 갈리거나, 두 개념이 섞이거나, 5점 차이를 설명하기 어렵습니다.
- `제거 후보`: 서로 다른 배경의 교사에게서 의도 밖 해석이 반복되거나, 수정해도 바람직한 답이 노출되거나, 다른 축의 핵심 개념으로 읽힙니다.
- 한 사람의 반응만으로 자동 교체하지 않습니다. 반대 사례도 기록하고, 어떤 배경과 장면에서 해석이 갈렸는지 함께 남깁니다.

## 5. C-3 파일럿 분석 원칙

- 응답은 익명 번호와 40개 응답값만 로컬 파일로 보관합니다.
- 실제 자료는 저장소에 커밋하지 않고 `/validation-data/` 아래에 둡니다.
- 분석 전에 제외 기준과 판단 기준을 먼저 기록합니다.
- 먼저 누락 응답, 한 번호만 반복한 응답, 문항별 5점 사용 분포를 확인하고 제외 기준 적용 전후 건수를 모두 남깁니다.
- 문항 응답 분포, 같은 축의 나머지 문항과의 관계, 축 사이 상관, 정방향·역방향 문항의 방식 효과를 봅니다.
- 5점 서열 응답에 맞는 상관과 추정 방법을 통계 검토자와 사전에 정합니다. 익숙하다는 이유만으로 일반 상관과 요인분석 기본값을 사용하지 않습니다.
- 탐색적 요인분석에서는 네 축을 강제로 넣은 결과만 보지 않고, 요인 수 판단 근거와 교차 적재 문항을 함께 기록합니다.
- 가능하면 문항 수정에 쓴 표본과 최종 구조를 확인할 표본을 나눕니다. 표본이 부족하면 `확인됨`이 아니라 `탐색 결과`로만 기록합니다.
- 내적 일관성 수치 하나를 타당성의 증거처럼 사용하지 않습니다.
- 점수 경계를 검토할 때에는 경계 부근의 분류 안정성과 측정 오차를 함께 보고, 결과 문구의 확신 수준도 이에 맞춥니다.
- 숫자가 좋지 않다고 임의 가중치를 주지 않습니다. 먼저 문항을 수정하거나 제거합니다.
- 표본 수 하나만으로 타당성을 선언하지 않습니다. 구성과 응답 품질을 함께 기록합니다.

## 6. B-2를 시작할 수 있는 조건

- 고위험 문항마다 인터뷰 근거가 있습니다.
- 수정 문항을 다른 교사가 다시 읽었을 때 같은 오해가 반복되지 않습니다.
- 네 축이 의도한 경계와 크게 어긋나지 않는다는 파일럿 근거가 있습니다.
- 점수 경계와 동점 처리 변경안이 A/B/C로 정리되어 사용자 승인을 받았습니다.
