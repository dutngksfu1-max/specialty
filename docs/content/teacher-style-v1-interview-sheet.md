## 마무리 질문

1. 답을 고르는 동안 검사 의도를 눈치챈 문항이 있었나요?
2. 교사로서 더 좋아 보이는 선택이 분명했던 문항이 있었나요?
3. 학생을 대하는 방식과 동료와 일하는 방식이 다른데 하나로 묶인 부분이 있었나요?
4. 결과가 실제 응답보다 더 강하게 말한 부분이 있었나요?
5. 결과를 동료와 나누기 망설여지는 표현이 있었나요?

## 인터뷰어 확인

- [ ] 먼저 축이나 바람직한 답을 설명하지 않았습니다.
- [ ] 열린 질문을 한 뒤에만 특정 위험을 확인했습니다.
- [ ] 참여자의 답을 맞다·좋다고 평가하지 않았습니다.
- [ ] 문항 이해와 결과 문장 평가는 서로 영향을 주지 않게 순서를 나눴습니다.
- [ ] 해석이 달랐던 사례와 반대 사례를 모두 기록했습니다.
