## 3. 축(Axis) 정의 — 4개 (초안 작성 완료 — 검수 대기)

각 축은 **서로 반대되는 두 가지 스타일**을 양 끝에 둡니다.
**어느 쪽도 더 좋거나 나쁘지 않아야 합니다.** 두 pole 이름을 나란히 놓았을 때
한쪽이 칭찬처럼, 다른 쪽이 흉처럼 읽히면 다시 씁니다.

### 작성된 축 4개 (DEC-023 초안 — **가장 먼저 검수해 주세요**)

네 축은 각각 **교사가 매일 실제로 마주하는 갈림길**에서 뽑았습니다.
`defaultPole`은 넷 다 `positive`입니다 (점수가 정확히 0일 때만 쓰이는 값 — DEC-001).

#### 축 1 — `axis-design` · 수업을 준비하는 방식

| | positive | negative |
|---|---|---|
| 이름 | **미리 그려 두는 준비형** | **흐름을 따라가는 조율형** |
| 짧은 이름 | 준비형 | 조율형 |
| 설명 | 학기와 단원의 흐름을 앞서 그려 두고, 그 지도를 따라 하루를 운영해요. 다음에 무엇이 오는지 알기 때문에 교실이 예측 가능해집니다. | 그날 교실에서 벌어지는 일을 보고 방향을 정해요. 계획에 매이지 않기 때문에 마침 찾아온 좋은 순간을 놓치지 않습니다. |

#### 축 2 — `axis-order` · 교실의 질서를 세우는 방식

| | positive | negative |
|---|---|---|
| 이름 | **약속을 먼저 세우는 구조형** | **관계를 먼저 쌓는 관계형** |
| 짧은 이름 | 구조형 | 관계형 |
| 설명 | 규칙과 절차를 분명히 해 두고 모두가 같은 그림을 보게 해요. 무엇을 기대받는지 알 때 아이들이 편안해진다고 봅니다. | 규칙보다 먼저 아이와의 신뢰를 쌓아요. 마음이 이어지면 교실은 자연스럽게 정돈된다고 봅니다. |

#### 축 3 — `axis-decision` · 결정할 때 먼저 보는 것

| | positive | negative |
|---|---|---|
| 이름 | **같은 기준을 지키는 형평형** | **각자의 사정을 살피는 맥락형** |
| 짧은 이름 | 형평형 | 맥락형 |
| 설명 | 누구에게나 같은 기준을 적용해, 아이들이 예외 없이 존중받는다고 느끼게 해요. 기준이 흔들리지 않아 설명하기도 쉽습니다. | 같은 행동도 그 아이가 놓인 사정에 따라 다르게 봐요. 지금 이 아이에게 무엇이 필요한지를 먼저 묻습니다. |

#### 축 4 — `axis-change` · 새로운 방식을 대하는 태도

| | positive | negative |
|---|---|---|
| 이름 | **먼저 해 보는 시도형** | **해 오던 것을 다지는 안정형** |
| 짧은 이름 | 시도형 | 안정형 |
| 설명 | 괜찮아 보이는 방법이 있으면 교실에서 직접 해 봐요. 해 보고 남는 것으로 다음 걸음을 정합니다. | 이미 잘 되던 방식을 조금씩 다듬어 완성도를 높여요. 검증된 것을 깊게 가져가는 데서 힘이 나옵니다. |

> **검수 포인트**
> - 네 축이 실제 교직 현장에서 관찰되는 차이인가요?
> - 양 끝 중 한쪽이 더 좋아 보이지는 않나요? (특히 축 3의 '형평형/맥락형')
> - 강의에서 이 네 가지로 대화를 끌어낼 수 있을까요?

## 5. 문항(Question) 정의 — 40개 (초안 작성 완료 — 검수 대기)

### 5.1 배분 규칙

```
총 40문항 = 축 4개 × 10문항
각 축의 10문항 중 polarity +1 을 5개, -1 을 5개로 배분합니다.
```

**왜 반반으로 나누나요?**
모든 문항을 같은 방향(+1)으로 쓰면, "그렇다"만 계속 누르는 사람(묵종 편향)의 점수가
한쪽으로 크게 쏠립니다. 반대 방향 문항을 섞으면 이 편향이 상쇄됩니다.

**polarity가 뭔가요?**
- `+1`: "그렇다"고 답할수록 **positive pole** 쪽으로 간다
- `-1`: "그렇다"고 답할수록 **negative pole** 쪽으로 간다

### 5.2 문항 작성 규칙

| 규칙 | 이유 |
|---|---|
| **기존 성격유형 검사 문항을 복제하거나 문장만 바꾸지 않는다** | 저작권 및 제품 정체성 |
| 교실·학교 상황을 구체적으로 담는다 | "나는 계획적이다" ✕ → "학기 시작 전에 한 달 치 수업 흐름을 미리 그려 둔다" ○ |
| 한 문항에 한 가지만 묻는다 | "나는 꼼꼼하고 빠르다" ✕ (두 가지를 묻고 있음) |
| 부정문을 피한다 | "~하지 않는다"는 5점 척도에서 혼란을 준다. polarity로 방향을 뒤집으세요 |
| 40자 내외로 짧게 | 40번 읽어야 합니다 |
| 옳고 그름을 암시하지 않는다 | "나는 학생을 잘 이해한다" ✕ (아니라고 답하기 어려움) |
| 빈도가 아니라 성향을 묻는다 | "일주일에 몇 번" ✕ → "~하는 편이다" ○ |
| 극단적 표현을 피한다 | "항상", "절대" ✕ |

| 32 | `part-4` | `axis-change` | `-1` | 1 | 새 방법을 쓰기 전에 먼저 해 본 동료의 이야기를 찾아보는 편이다. |
| 33 | `part-4` | `axis-design` | `+1` | 1 | 계획한 순서대로 흘러갈 때 수업이 잘 풀렸다고 느낀다. |
| 34 | `part-4` | `axis-order` | `+1` | 1 | 예측 가능한 하루 흐름이 아이들을 편안하게 한다고 생각한다. |
| 35 | `part-4` | `axis-decision` | `+1` | 1 | 같은 상황에는 같은 안내를 하는 편이 아이들에게 공정하다고 본다. |
| 36 | `part-4` | `axis-change` | `+1` | 1 | 잘 안 되더라도 새로 해 보는 편이 배우는 게 많다고 생각한다. |
| 37 | `part-4` | `axis-design` | `-1` | 1 | 그날 교실 분위기를 보고 활동을 고르는 편이다. |
| 38 | `part-4` | `axis-order` | `-1` | 1 | 교실 분위기가 좋아지면 약속은 자연스럽게 지켜진다고 생각한다. |
| 39 | `part-4` | `axis-decision` | `-1` | 1 | 아이마다 다르게 대하는 것이 오히려 공평하다고 느낀다. |
| 40 | `part-4` | `axis-change` | `-1` | 1 | 익숙한 방식을 깊이 다듬을 때 수업이 단단해진다고 느낀다. |

> `weight`는 **전부 1**입니다. 검증 데이터가 없는 MVP에서 특정 문항에
> 임의 가중치를 주지 않습니다 (`docs/PRD.md` F-4.2).

## 6. 결과 프로필(ResultProfile) — 16개 (초안 작성 완료 — 검수 대기)

축 4개 × 방향 2가지 = **2⁴ = 16개 조합**입니다. **하나도 빠뜨리면 안 됩니다.**

### 6.1 작성된 결과 프로필 16개 (초안 — 검수 대기)

`P` = positive pole, `N` = negative pole. 축 순서는 axes 배열 순서입니다.
축1 수업 준비 / 축2 교실 질서 / 축3 결정 기준 / 축4 새로운 방식

| # | 축1 | 축2 | 축3 | 축4 | resultKey (내부용) | 결과 제목 | 한 줄 설명 |
|---|---|---|---|---|---|---|---|
| 1 | P | P | P | P | `pppp` | **틀을 세우고 계속 손보는 교실** | 탄탄한 틀을 먼저 만들고, 그 안에서 새로운 것을 계속 시험해 보는 편이에요. |
| 2 | P | P | P | N | `pppn` | **한 번 세운 질서를 오래 다지는 편** | 미리 준비하고 기준대로 운영하며, 잘 되던 방식을 해마다 더 정교하게 다듬어요. |
| 3 | P | P | N | P | `ppnp` | **촘촘한 틀 안에서 한 명씩 살피는 편** | 구조는 단단히 세우되, 그 안에서 아이마다 다른 길을 열어 주는 편이에요. |
| 4 | P | P | N | N | `ppnn` | **단단한 하루에 여지를 남겨 두는 편** | 익숙한 틀을 꾸준히 지키면서, 그 안에 아이를 위한 여백을 남겨 두는 편이에요. |
| 5 | P | N | P | P | `pnpp` | **미리 그려 두고 마음으로 여는 교실** | 수업은 미리 준비하고 교실은 관계로 여는 편이에요. 새로운 시도도 잦고요. |
| 6 | P | N | P | N | `pnpn` | **조용히 준비해 한결같이 지키는 편** | 미리 준비해 두고 관계로 이끌며, 한 번 정한 기준은 오래 지켜 가는 편이에요. |
| 7 | P | N | N | P | `pnnp` | **계획은 촘촘하게, 사람은 넉넉하게** | 준비는 빈틈없이 하면서, 아이 앞에서는 규칙보다 사정을 먼저 보는 편이에요. |
| 8 | P | N | N | N | `pnnn` | **천천히 준비해 오래 곁에 머무는 편** | 미리 준비해 두고, 아이 곁에서 천천히 오래 지켜보며 때를 기다리는 편이에요. |
| 9 | N | P | P | P | `nppp` | **규칙은 분명하게, 수업은 자유롭게** | 교실 약속은 또렷하게 세우고, 수업은 그날 흐름을 따라 자유롭게 굴리는 편이에요. |
| 10 | N | P | P | N | `nppn` | **흐름은 유연하게, 기준은 한결같이** | 수업은 그날에 맞추면서도, 교실 약속과 기준은 흔들지 않는 편이에요. |
| 11 | N | P | N | P | `npnp` | **약속을 지키며 새 길을 내는 편** | 약속은 지키되 수업은 흐름에 맡기고, 아이마다 다른 길을 새로 내 보는 편이에요. |
| 12 | N | P | N | N | `npnn` | **익숙한 틀 위에서 유연하게 움직이는 편** | 오래 써 온 틀 위에서, 그날과 그 아이에 맞춰 조용히 움직이는 편이에요. |
| 13 | N | N | P | P | `nnpp` | **그날의 교실에서 답을 찾는 편** | 그날 아이들과의 흐름에서 수업을 만들고, 기준만은 흔들지 않는 편이에요. |
| 14 | N | N | P | N | `nnpn` | **관계로 이끌고 기준은 지키는 편** | 관계로 교실을 이끌면서, 정한 기준과 해 온 방식은 꾸준히 지켜 가는 편이에요. |
| 15 | N | N | N | P | `nnnp` | **순간마다 아이에게 맞춰 움직이는 편** | 그날 그 아이에게 맞춰 방식을 바꾸며, 새로운 길을 자주 만들어 보는 편이에요. |
| 16 | N | N | N | N | `nnnn` | **아이 곁에서 천천히 함께 걷는 편** | 계획과 기준을 앞세우지 않고, 아이 곁에서 천천히 함께 걸어가는 편이에요. |

> `resultKey`는 **내부 식별자일 뿐 화면에 절대 노출하지 않습니다.**
> 사용자에게는 `title`(결과 제목)만 보입니다.
> 이 키는 기존 성격유형 검사의 4글자 코드와 무관한 자체 표기입니다.
>
> **본문(리듬 / 빛나는 순간 / 바쁠 때 / 동료와 / 협업 2묶음)은 분량이 커서
> 이 문서에 옮기지 않았습니다.** 화면에서 직접 읽어 보시는 편이 검수에 편하고,
> 원문은 `src/infrastructure/content/packages/teacher-style-v1/profiles.ts`에 있습니다.
> 두 곳에 나눠 적으면 반드시 어긋나기 때문에 한 곳에만 두었습니다.

### 6.2 프로필 작성 양식 (16번 반복)

```
resultKey        : [위 표의 키]
poles            : { 축1: P/N, 축2: P/N, 축3: P/N, 축4: P/N }

title            : [결과 제목]
                   예시 형태 — "차분하게 리듬을 만드는 교실 운영자"
                   ※ 12~20자 권장. 360px 화면에서 2줄 이내
                   ※ "~형", "~타입" 같은 분류 어미를 피합니다

oneLiner         : [한 줄 설명. 30~50자]

rhythm           : [나의 교직 리듬 — 2~4문장]
                   이 사람이 하루를, 한 학기를 어떤 흐름으로 보내는지

shiningMoments   : [교실에서 빛나는 순간 — 3개 항목]
                   - [항목 1]
                   - [항목 2]
                   - [항목 3]

underPressure    : [바쁠 때 나타날 수 있는 모습 — 2~3개 항목]
                   - [항목 1]
                   - [항목 2]
                   ※ 비난이 아니라 "이럴 때가 있어요" 톤

withColleagues   : [동료와 함께 일할 때 — 2~3개 항목]
                   - [항목 1]
                   - [항목 2]

collaboration
  naturalFit     : [호흡이 자연스러운 스타일 — 2개 항목]
                   - [스타일 설명 1]
                   - [스타일 설명 2]
  needsTuning    : [조율하면 더 편한 스타일 — 2개 항목]
                   - [스타일 설명 1]
                   - [스타일 설명 2]
```

### 6.3 결과 텍스트 작성 규칙

**쓰지 않는 표현**

| 금지 | 이유 |
|---|---|
| "궁합이 좋은 사람 / 나쁜 사람" | 관계를 단정하고 갈등을 만듭니다 |
| "당신은 ~형입니다" | 사람을 상자에 넣는 말투 |
| 등급·순위·백분위 | 검사의 목적이 평가가 아닙니다 |
| "게으른", "우유부단한", "예민한" 등 낙인 | 교사에게 실례가 됩니다 |
| 4글자 코드·기존 성격유형 검사 명칭 | 절대 금지 |
| 과도한 이모지 | 성숙한 톤을 해칩니다 |

**쓰는 표현**

| 권장 | 예 |
|---|---|
| "~하는 편이에요" | 단정 대신 경향 |
| "~할 때가 많아요" | |
| "호흡이 자연스러운 스타일" | 궁합 대신 |
| "조율하면 더 편한 스타일" | |
| 약점을 강점의 그림자로 | "천천히 확인하는 편이라 결정이 늦어질 때가 있어요" |

**`collaboration` 작성 시 주의**

`needsTuning`(조율하면 더 편한 스타일)은 **"이 사람과 맞지 않는다"가 아니라
"이런 점을 미리 이야기해 두면 서로 편해진다"**는 뜻입니다.
구체적인 조율 방법을 한 문장 덧붙이면 강의장에서 대화 소재가 됩니다.

예시 형태:
> "속도를 먼저 내는 스타일과는, 시작 전에 '언제까지'를 함께 정해 두면 훨씬 편해져요."

## 8. 자동 검증 항목

콘텐츠를 넣으면 아래를 자동으로 확인합니다. 하나라도 실패하면 `INVALID_CONTENT_PACKAGE` 오류가 납니다.

- [ ] 모든 `question.axisId`가 `axes`에 존재
- [ ] 모든 `question.sectionId`가 `sections`에 존재
- [ ] `question.order`가 1부터 빠짐없이 연속
- [ ] `resultProfiles` 개수 = 2 ^ (축 개수) = 16
- [ ] `resultProfiles`의 `poles` 조합에 중복·누락 없음
- [ ] `intensityBands`가 0부터 최대 절대값까지 빈틈·겹침 없이 덮음
- [ ] `scale.options`에 `centerValue`(3)가 존재
- [ ] `polarity`가 `+1` 또는 `-1`
- [ ] `weight`가 모두 1 (MVP 규칙)
- [ ] 축별 문항 수가 균등 (경고 수준)
