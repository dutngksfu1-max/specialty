# docs/reference — 검수용 원본 참고 자료

이 폴더는 **콘텐츠(축·문항·결과 텍스트)를 검수하고 고도화할 때 참고하는 원본 자료**를 두는 곳입니다.

## 규칙

1. **이 폴더의 자료는 git에 올리지 않습니다.** (`.gitignore`로 차단, 이 README만 예외)
   - 저작권이 있는 자료일 수 있고, 저장소가 무거워집니다.
2. **`public/`에 두지 않습니다.** `public/` 안의 파일은 배포 후 인터넷 누구나 URL로 내려받을 수 있습니다.
3. **파일명에 금지 표현을 쓰지 않습니다** (`AGENTS.md` 1.1).
   - ❌ `MBTI_문항지.pdf` / ✅ `reference-01.pdf`
4. **원본 문장을 콘텐츠로 복제하거나 문장만 바꿔 쓰지 않습니다** (`AGENTS.md` 1.1).
   - 참고 자료에서 가져오는 것은 **"무엇을 재려는가"라는 개념**뿐입니다.
   - 문항 문장은 교직 맥락에서 **새로 창작**합니다.
