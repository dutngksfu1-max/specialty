# 클래스렌즈 유형 캐릭터 아트 디렉션

> 상태: DEC-054 · DEC-068 확정 · 2026-08-31
> 적용 위치: 결과 히어로 · `public/assessments/teacher-style/types/`

## 1. 제작 수량

총 **32종**입니다.

- `16유형 × 남성·여성 = 32종`
- 모든 결과는 채점에서 확정된 네 방향의 유형 캐릭터를 사용합니다

## 2. 공통 시각 언어

- 기존 `hero-teaching-journey.webp`의 웜 아이보리 종이, 얇은 다크 세이지 선, 옅은 세이지·오커·클레이 수채 번짐을 잇습니다.
- 인물은 약 7.5등신의 성인 비례로 그리고, 전체 높이의 약 70%를 차지하는 전신 중심 구도를 씁니다.
- 얼굴은 작고 절제해 표정이 성격을 단정하지 않게 합니다. 큰 눈·볼터치·과장된 머리 비율은 금지합니다.
- 교실 전체나 작업대가 주인공이 되지 않게 하고, 인물 가까이에 핵심 소품만 둡니다.
- 유형은 색이 아니라 **자세·행동·도구·카드의 동선**으로 구분합니다.
- 파일은 `480×640` JPG이며 외부 이미지·폰트·CDN을 사용하지 않습니다.

## 3. 성별 표현 규칙

- 사용자가 고른 `남성`·`여성`은 자연스러운 성인 실루엣, 머리, 절제된 업무 복장에서 알아볼 수 있게 합니다.
- 같은 유형의 남녀는 같은 행동 개념과 핵심 소품을 공유합니다.
- 남성은 원칙·계획, 여성은 맥락·협업처럼 역할을 성별에 배정하지 않습니다.
- 성별 외 연령대와 인종은 특정하지 않습니다.
- 성별 값은 캐릭터 선택에만 쓰고 채점·프로필 문구에는 영향을 주지 않습니다.

## 4. 네 축의 조형 문법

| 축 | 방향 | 캐릭터에서 읽히는 형태 |
|---|---|---|
| 힘을 얻는 방향 | 교류 G | 몸이 바깥으로 열리고, 대화 카드·공유 제스처가 인물 가까이에 있음 |
|  | 몰입 D | 시선과 팔이 노트·자료 안쪽으로 모이고, 혼자 정리하는 자세 |
| 먼저 눈에 들어오는 것 | 실제 A | 관찰 기록·교실 재료·구체 카드처럼 손에 잡히는 증거 |
|  | 가능성 O | 가지치는 아이디어·열린 스케치북·여러 경로 |

|  | 맥락 C | 대화 메모·연결 실·서로 다른 관점 카드 |

|  | 유연 L | 옮기는 카드·갈라지는 경로·비대칭 동작 |

## 5. 유형별 장면 설계

| 코드 | 핵심 장면 | 구분 소품·동작 |
|---|---|---|
| GARM | 팀의 수업 계획을 차분히 여는 교사 | 토론 카드, 실제 교구, 기준표, 3단계 플래너 |
| GARL | 기준을 잡고 현장에서 순서를 바꾸는 교사 | 실물 재료 트레이, 원칙 카드, 움직이는 활동 카드 |
| GACM | 관찰한 사실과 동료의 말을 일정에 엮는 교사 | 관찰 기록, 대화 메모, 정돈된 시간선 |
| GACL | 실제 장면을 들으며 바로 경로를 조정하는 교사 | 현장 노트, 맥락 연결선, 옮겨지는 카드 |
| GORM | 가능성을 사람들과 나누고 계획으로 세우는 교사 | 가지치는 아이디어, 루브릭, 마일스톤 |
| GORL | 분명한 기준 아래 여러 길을 시험하는 교사 | 원칙 앵커, 회전하는 경로 타일, 아이디어 카드 |
| GOCM | 여러 관점을 모아 미래 계획으로 묶는 교사 | 대화 카드, 가능성 묶음, 계획선 |
| GOCL | 대화 속 아이디어를 자유롭게 다시 잇는 교사 | 열린 스케치북, 맥락 카드, 굽은 복수 경로 |
| DARM | 실제 자료를 기준표와 대조해 미리 정리하는 교사 | 교실 자료, 루브릭, 탭 폴더, 곧은 순서선 |
| DARL | 원칙을 손에 쥔 채 현장 자료를 재배치하는 교사 | 실물 카드, 기준 카드, 움직이는 활동 타일 |
| DACM | 구체 관찰을 맥락과 함께 일정으로 정리하는 교사 | 관찰 카드, 두 맥락 메모, 시간선 폴더 |
| DACL | 기록을 깊이 읽고 상황에 맞는 위치를 찾는 교사 | 일화 기록, 맥락 실, 이동 카드 |
| DORM | 혼자 그린 가능성을 기준과 장기 계획으로 세우는 교사 | 미래 스케치, 원칙 그리드, 마일스톤 |
| DORL | 기준을 잃지 않고 새로운 갈림길을 시험하는 교사 | 원칙 나침 카드, 두 갈래 경로, 열린 노트 |
| DOCM | 가능성과 맥락을 조용히 종합해 계획하는 교사 | 아이디어 카드, 맥락 실, 순서 폴더 |
| DOCL | 미묘한 맥락을 읽으며 가능성의 길을 다시 잇는 교사 | 열린 스케치북, 곡선 연결, 움직이는 경로 |

## 6. 파일 계약

유형별 파일은 아래 규칙을 따릅니다.

```text
<4렌즈코드>-male.jpg
<4렌즈코드>-female.jpg
```

16개 코드는 `garm`, `garl`, `gacm`, `gacl`, `gorm`, `gorl`, `gocm`, `gocl`,
`darm`, `darl`, `dacm`, `dacl`, `dorm`, `dorl`, `docm`, `docl`입니다.

`presentation.ts`는 결과 키마다 `{ male, female }` 한 쌍을 주입합니다. 결과 화면은
`snapshot.characterGender`로 한 파일만 고릅니다. 기존 저장 결과처럼 성별 값이
`null`이면 임의로 추정하지 않고 캐릭터를 생략합니다.

## 7. 생성 프롬프트 기준

모든 자산은 기존 대표 그림을 스타일 참조로 사용하고 아래 공통 조건을 적용했습니다.

```text
Warm ivory handmade paper, restrained sage and muted ochre/clay watercolor,
delicate dark-sage linework, mature adult teacher, realistic adult proportions,
full figure as the main subject, sparse nearby props, no room interior,
no text or logo, no oversized eyes, blush, mascot, chibi, anime, 3D, or photorealism.
```

유형별 프롬프트에는 5장의 장면·소품·동작을 덧붙이고, 남녀 한 쌍에는 동일한 유형 문장을 사용했습니다.

## 8. 검수 체크리스트

- [ ] 사용 중인 JPG 32개가 모두 존재하며 파일명이 중복되지 않음
- [ ] 같은 유형의 남녀가 같은 행동 개념으로 읽힘
- [ ] 16유형이 색 없이 자세·소품으로 구분됨
- [ ] 유아적 비례·성별 역할 고정관념·텍스트·로고가 없음
- [ ] 360px 결과 히어로에서 인물이 잘리지 않고 가로 스크롤이 없음
